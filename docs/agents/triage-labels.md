# 分诊标签

工程技能使用五个标准分诊角色。本文件将这些角色映射到本仓库问题跟踪器中实际使用的标签。

| mattpocock/skills 中的标签 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估该问题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完整，可由 AFK Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个分诊角色（例如“应用 AFK-ready 分诊标签”）时，使用此表中对应的实际标签名称。

如果本仓库调整了标签命名，请修改“本仓库使用的标签”一列。
